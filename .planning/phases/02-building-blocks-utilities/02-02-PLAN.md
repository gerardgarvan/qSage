**tripleprod(z, q, T):**
Formula: `prod_{i=1}^{N} (1 - z*q^{i-1}) * (1 - q^i/z) * (1-q^i)` where N is large enough that `q^N > T`.

CRITICAL implementation decision: `z` may be a scalar (e.g. `q` passed as `q_ring.gen()`) or a bivariate variable. Use the same scalar-vs-bivariate detection as `theta`:
- If `z` can be coerced to a ring element of the q-series ring: build univariate
- Otherwise: build bivariate

For the Euler pentagonal test case `tripleprod(q, q**3, T)`, `z=q` is a series element and `q=q**3` is also a series element. Both live in `LaurentSeriesRing(QQ, 'q')`. The univariate path handles this.

```python
def tripleprod(z, q, T):
    """Jacobi triple product: prod_{i>=1}(1-z q^{i-1})(1-q^i/z)(1-q^i) to O(q^T).
    
    z bivariate when passed as a ring variable, univariate when scalar or series.
    Oracle: Garvan tripleprod doc page; tutorial §6.1 for Euler pentagonal.
    """
    from sage.all import parent
    R_q = LaurentSeriesRing(QQ, 'q')
    
    # Try to work in the ring containing both z and q
    # If z is already a LaurentSeries element, work in R_q directly
    try:
        # This works if z is a LaurentSeries or coercible to one
        q_r = R_q(q)
        z_r = R_q(z)
        result = R_q.one()
        i = 1
        while i <= T + 1:
            qpow = q_r**i
            # Guard: if qpow is O(q^T) we can stop adding factors (they contribute nothing new)
            factor1 = R_q.one() - z_r * q_r**(i - 1)
            factor2 = R_q.one() - q_r**i / z_r
            factor3 = R_q.one() - q_r**i
            result = (result * factor1 * factor2 * factor3).add_bigoh(T)
            i += 1
        return QSeries(result.add_bigoh(T), T=T)
    except (TypeError, ValueError, ZeroDivisionError):
        # Bivariate: z is a LaurentPolynomialRing element
        Rz = LaurentPolynomialRing(QQ, 'z')
        zvar = Rz.gen()
        Rq = LaurentSeriesRing(Rz, 'q')
        qv = Rq.gen()
        result = Rq.one()
        for i in range(1, T + 2):
            factor1 = Rq.one() - zvar * qv**(i - 1)
            factor2 = Rq.one() - zvar**(-1) * qv**i
            factor3 = Rq.one() - qv**i
            result = (result * factor1 * factor2 * factor3).add_bigoh(T)
        return QSeries(result.add_bigoh(T), T=T, R=Rz)
```

**quinprod(a, b, q, T):**
Per key_research_findings, canonical signature is `quinprod(a, b, q, T)` (4 args).
Per D-05/D-06: T='prodid' or T='seriesid' -> return string; T=integer -> return QSeries.

Watson's quintuple product identity:
`prod_{n>=1}(1-q^n)(1-a q^{n-1})(1 - q^n/a)(1-b q^{n-1})(1 - q^n/b)(1 - ab q^{n-1})(1 - q^n/(ab))(1 - (a/b) q^{n-1})(1 - (b/a) q^n)`
(This is one standard form; exact factors vary by source. Use the form: five Jacobi-like triple products.)

For identity strings, return a descriptive ASCII string, e.g.:
- 'prodid': `"PROD(n>=1)(1-q^n)(1-a*q^(n-1))(1-q^n/a)(1-b*q^(n-1))(1-q^n/b)(1-a*b*q^(n-1))(1-q^n/(a*b)) = SUM ..."`
- 'seriesid': `"SUM_{n=-inf}^{inf} a^n * (a^(3n) - b^{-1} * q^{n(3n+1)/2}) = ..."`

For T=integer: build the product in the bivariate ring `LaurentPolynomialRing(QQ, ['a','b'])`.

```python
def quinprod(a, b, q, T):
    """Watson's quintuple product identity.
    
    T='prodid' or T='seriesid': returns identity string (D-05).
    T=integer: returns QSeries Laurent in a,b (D-06).
    Canonical 4-arg signature per Garvan doc page.
    Oracle: Garvan quinprod doc page.
    """
    if isinstance(T, str):
        if T == 'prodid':
            return (
                "quinprod identity (product form): "
                "prod_{n>=1}(1-q^n)(1-a*q^{n-1})(1-q^n/a)"
                "(1-b*q^{n-1})(1-q^n/b)(1-a*b*q^{n-1})(1-q^n/(a*b)) = "
                "sum_{n=-inf}^{inf} a^n*(a^{3n} - b^{-1}*q^{n(3n+1)/2+1/2})"
            )
        elif T == 'seriesid':
            return (
                "quinprod identity (series form): "
                "sum_{n=-inf}^{inf} (-1)^n a^n q^{n(n-1)/2}"
                "*(1 - a*b*q^n) = prod_{n>=1}(1-q^n)(1-a*q^{n-1})(1-q^n/a)"
                "(1-b*q^{n-1})(1-q^n/b)"
            )
        else:
            raise ValueError(f"quinprod: T must be integer, 'prodid', or 'seriesid'; got {T!r}")
    # T is an integer: build QSeries
    # Build bivariate product in LaurentPolynomialRing(QQ, ['a','b'])
    Rab = LaurentPolynomialRing(QQ, ['a', 'b'])
    a_var, b_var = Rab.gens()
    Rq = LaurentSeriesRing(Rab, 'q')
    qv = Rq.gen()
    result = Rq.one()
    for i in range(1, T + 2):
        exp_prev = i - 1  # q^{n-1}
        exp_cur = i       # q^n
        # Seven factors of Watson's quintuple product
        factors = [
            Rq.one() - qv**exp_cur,                         # (1-q^n)
            Rq.one() - a_var * qv**exp_prev,                # (1-a q^{n-1})
            Rq.one() - a_var**(-1) * qv**exp_cur,           # (1-q^n/a)
            Rq.one() - b_var * qv**exp_prev,                # (1-b q^{n-1})
            Rq.one() - b_var**(-1) * qv**exp_cur,           # (1-q^n/b)
            Rq.one() - a_var * b_var * qv**exp_prev,        # (1-ab q^{n-1})
            Rq.one() - a_var**(-1) * b_var**(-1) * qv**exp_cur,  # (1-q^n/(ab))
        ]
        for f in factors:
            result = (result * f).add_bigoh(T)
    return QSeries(result.add_bigoh(T), T=T, R=Rab)
```

**winquist(a, b, q, T):**
Formula from RESEARCH.md Mathematical Formulas section:
```
winquist(a,b,q,T) = (a;q)_inf * (q/a;q)_inf * (b;q)_inf * (q/b;q)_inf *
                    (ab;q)_inf * (q/(ab);q)_inf * (a/b;q)_inf * (b/(aq);q)_inf *
                    (q;q)_inf^2
```
where `(x;q)_inf = prod_{i=0}^{inf}(1 - x * q^i)`.

MANDATORY: `a` and `b` MUST be elements of `LaurentPolynomialRing(QQ, ['a','b'])`.
Passing Python scalar 1 as `a` produces `(1;q)_inf = prod(1 - 1*q^i)` which is zero (first factor = 0).
The function MUST enforce this contract and raise `TypeError` if `a` or `b` are Python int/QQ scalars.

The Garvan doc page oracle "winquist(a,b,q,T) = 1-10q+35q^2-..." is the bivariate series
evaluated symbolically. To obtain integer-coefficient series, the caller specializes by substituting
concrete values for `a` and `b` AFTER construction using polynomial ring specialization:
```python
Rab = LaurentPolynomialRing(QQ, ['a', 'b'])
a_var, b_var = Rab.gens()
result = winquist(a_var, b_var, q, T)
# To specialize a=exp(2*pi*i/3), b=exp(2*pi*i/3): use result.series.map_coefficients(...)
```

```python
def winquist(a, b, q, T):
    """Winquist's identity: 9-factor infinite product to O(q^T).
    
    winquist(a,b,q,T) = (a;q)_inf * (q/a;q)_inf * (b;q)_inf * (q/b;q)_inf *
                        (ab;q)_inf * (q/(ab);q)_inf * (a/b;q)_inf * (b/(aq);q)_inf *
                        (q;q)_inf^2
    
    REQUIRES: a and b must be LaurentPolynomialRing elements (not Python int/QQ).
    The product would be zero for scalar a=1 since (1;q)_inf has a zero factor.
    
    To get specialised series: substitute after construction.
    
    Oracle: Garvan winquist doc page; RESEARCH.md Mathematical Formulas.
    """
    # Validate: a and b must not be plain Python scalars
    try:
        if int(a) == a or int(b) == b:
            raise TypeError(
                "winquist: a and b must be LaurentPolynomialRing elements, not Python scalars. "
                "Build Rab = LaurentPolynomialRing(QQ, ['a','b']); a, b = Rab.gens(); "
                "then call winquist(a, b, q, T). "
                "Scalar values make (scalar;q)_inf = 0 when scalar = integer."
            )
    except (TypeError, ValueError):
        pass  # non-integer types are fine

    Rab = LaurentPolynomialRing(QQ, ['a', 'b'])
    a_var, b_var = Rab.gens()
    Rq = LaurentSeriesRing(Rab, 'q')
    qv = Rq.gen()

    # Coerce a and b to Rab elements
    try:
        a_r = Rab(a)
        b_r = Rab(b)
    except (TypeError, ValueError) as exc:
        raise TypeError(f"winquist: cannot coerce a={a!r} or b={b!r} to LaurentPolynomialRing(QQ, ['a','b']): {exc}")

    def _qpoch_inf(x):
        """(x; q)_inf = prod_{i=0}^{T} (1 - x * q^i) to O(q^T), working in Rq."""
        res = Rq.one()
        for i in range(T + 1):
            res = (res * (Rq.one() - Rq(x) * qv**i)).add_bigoh(T)
        return res

    # The 8 Pochhammer factors + (q;q)_inf^2
    # Factor semantics: (a;q)_inf uses a as a Laurent polynomial coefficient
    # (q/a;q)_inf = prod(1 - q*a^{-1} * q^i) = prod(1 - a^{-1} * q^{i+1})
    result = Rq.one()
    factors = [
        _qpoch_inf(a_r),              # (a;q)_inf
        _qpoch_inf(a_r**(-1) * qv),  # (q/a;q)_inf
        _qpoch_inf(b_r),              # (b;q)_inf
        _qpoch_inf(b_r**(-1) * qv),  # (q/b;q)_inf
        _qpoch_inf(a_r * b_r),        # (ab;q)_inf
        _qpoch_inf((a_r * b_r)**(-1) * qv),  # (q/(ab);q)_inf
        _qpoch_inf(a_r * b_r**(-1)), # (a/b;q)_inf
        _qpoch_inf(a_r**(-1) * b_r * qv),    # (b/(aq);q)_inf = (aq)^{-1}*b = b*q/a shifted
        _qpoch_inf(qv),               # (q;q)_inf — first factor of (q;q)_inf^2
        _qpoch_inf(qv),               # (q;q)_inf — second factor
    ]
    for f in factors:
        result = (result * f).add_bigoh(T)

    return QSeries(result.add_bigoh(T), T=T, R=Rab)
```

NOTE on the "(q/a;q)_inf" factor: `(q/a;q)_inf = prod_{i=0}^{inf}(1 - (q/a)*q^i) = prod_{i=0}^{inf}(1 - a^{-1}*q^{i+1})`. The call `_qpoch_inf(a_r**(-1) * qv)` passes `x = a^{-1} * q` so `(1 - x * q^i) = (1 - a^{-1} * q^{i+1})`. This is correct.

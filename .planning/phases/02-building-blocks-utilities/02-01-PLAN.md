**aqprod(a, q, n):**
Formula: `(a;q)_n = prod_{i=0}^{n-1} (1 - a*q^i)`, `(a;q)_0 = 1`.
v1.3 supports negative n; skip for v1.0 (raise NotImplementedError if n < 0).

Implementation: Build in `LaurentSeriesRing(QQ, 'q')`. CRITICAL: `a` and `q` may already be ring elements (caller passes `q_ring.gen()`), so construct the ring and coerce if needed. Simplest approach: accept `a` and `q` as arbitrary expressions, build a plain Python product, then coerce to QSeries.

```python
def aqprod(a, q, n):
    """Finite q-Pochhammer symbol (a;q)_n = prod_{i=0}^{n-1}(1 - a*q^i).
    
    n=0 returns 1. Negative n not supported in v1.0.
    Oracle: Garvan aqprod doc page.
    """
    if n < 0:
        raise NotImplementedError("aqprod: negative n not yet supported")
    R = LaurentSeriesRing(QQ, 'q')
    qvar = R.gen()
    # Coerce a and q into R if they are not already
    try:
        a_r = R(a)
    except Exception:
        a_r = a
    try:
        q_r = R(q)
    except Exception:
        q_r = q
    result = R.one()
    for i in range(n):
        result *= (R.one() - a_r * q_r**i)
    return QSeries(result.add_bigoh(n + 1), T=n + 1)
```

NOTE: When `a = q` (same ring element), `a_r = q_r = R.gen()`. The product correctly builds `(1-q)(1-q^2)...(1-q^n)`.

**qbin(q, m, n):**
Wraps `sage.arith.misc.q_binomial`. Maple arg order: `qbin(q, m, n)` with m<=n.
Sage arg order: `q_binomial(n, k, q)` — n is upper, k is lower index.
Return zero when m < 0 or m > n.

```python
def qbin(q, m, n):
    """Gaussian binomial (q-binomial coefficient). Returns 0 if not 0<=m<=n.
    
    Maple: qbin(q, m, n); wraps sage.arith.misc.q_binomial(n, m, q).
    Oracle: Garvan qbin doc page.
    """
    if not (0 <= m <= n):
        R = LaurentSeriesRing(QQ, 'q')
        return QSeries(R.zero().add_bigoh(1), T=0)
    R = LaurentSeriesRing(QQ, 'q')
    qvar = R.gen()
    # Sage: q_binomial(n, k, q) where n=upper, k=lower; Maple lower index = m
    raw = R(q_binomial(n, m, qvar))
    return QSeries(raw.add_bigoh(n * m + 1), T=n * m + 1)
```

**etaq(q, k, T):**
Wraps `sage.functions.other.qexp_eta`. Formula: `prod_{n>=1}(1-q^{kn})`.
Pass `qvar**k` as first arg to `qexp_eta`.

```python
def etaq(q, k, T):
    """Eta quotient prod_{n>=1}(1 - q^{kn}) to O(q^T). No q^{1/24} factor.
    
    Wraps sage.functions.other.qexp_eta(q^k, T).
    Oracle: Garvan etaq doc page.
    """
    R = LaurentSeriesRing(QQ, 'q')
    qvar = R.gen()
    raw = qexp_eta(qvar**k, T)
    # qexp_eta returns a power series; coerce to LaurentSeries
    raw_L = R(raw)
    return QSeries(raw_L.add_bigoh(T), T=T)
```

**jacprod(a, b, q, T):**
Formula: `(q^a; q^b)_inf * (q^{b-a}; q^b)_inf` — both infinite products truncated to O(q^T).
Implement as two partial products: multiply `(1 - q^{a + b*i})` for i=0,1,... while `a + b*i < T`, similarly for `(1 - q^{(b-a) + b*i})`.

```python
def jacprod(a, b, q, T):
    """Jacobi product (q^a;q^b)_inf * (q^{b-a};q^b)_inf to O(q^T).
    
    a, b are positive integers with a < b.
    Oracle: Garvan jacprod doc page.
    """
    R = LaurentSeriesRing(QQ, 'q')
    qvar = R.gen()
    result = R.one()
    # Factor 1: (q^a; q^b)_inf — product of (1 - q^{a + b*i}) for i=0,1,...
    i = 0
    while a + b * i < T:
        result *= (R.one() - qvar**(a + b * i))
        i += 1
    # Factor 2: (q^{b-a}; q^b)_inf — product of (1 - q^{(b-a) + b*i}) for i=0,1,...
    j = 0
    while (b - a) + b * j < T:
        result *= (R.one() - qvar**((b - a) + b * j))
        j += 1
    return QSeries(result.add_bigoh(T), T=T)
```

**theta(z, q, T):**
Formula: `sum_{i=-T}^{T} z^i * q^{i^2}`. Bivariate Laurent series.
Use Pattern 3 (bivariate ring construction). CRITICAL: the function must work when called with `z=-1` (substitution yields univariate series) AND when called with `z = Rz.gen()` (yields bivariate). Handle both cases: if `z` is a Sage symbolic or Laurent polynomial element, build two-variable ring; if `z` is a scalar (int, QQ element), build univariate ring and substitute.

```python
def theta(z, q, T):
    """Jacobi theta function sum_{i=-T}^{T} z^i q^{i^2}.
    
    Bivariate when z is a ring variable; univariate when z is a scalar.
    Oracle: Garvan theta doc page.
    """
    R_q = LaurentSeriesRing(QQ, 'q')
    qvar = R_q.gen()
    try:
        # Scalar z: build univariate series
        z_val = QQ(z)
        result = R_q.zero()
        for i in range(-T, T + 1):
            result += z_val**i * qvar**(i * i)
        return QSeries(result.add_bigoh(T * T + 1), T=T * T + 1)
    except (TypeError, ValueError):
        # Non-scalar z: build bivariate ring
        Rz = LaurentPolynomialRing(QQ, 'z')
        zvar = Rz.gen()
        Rq = LaurentSeriesRing(Rz, 'q')
        qv = Rq.gen()
        result = Rq.zero()
        for i in range(-T, T + 1):
            result += zvar**i * qv**(i * i)
        return QSeries(result.add_bigoh(T * T + 1), T=T * T + 1, R=Rz)
```

**theta2(q, T):**
Formula: `sum_{n=-inf}^{inf} q^{(n+1/2)^2}`. Fractional shift r=1/4.
KEY: `(n+1/2)^2 = n^2 + n + 1/4`. Factor out `q^(1/4)`. Integer part of exponent = `n^2 + n`.
For n=0,-1: both give integer part 0 -> coefficient = 2.
For n=1,-2: integer part = 1^2+1=2 -> coefficient = 2.
For n=2,-3: integer part = 2^2+2=6 -> coefficient = 2.

```python
def theta2(q, T):
    """Jacobi theta2 = sum_{n} q^{(n+1/2)^2}, stored as q^{1/4} * (series with integer powers).
    
    QSeries.r = QQ(1, 4). Series coefficients: 2 at exponent n^2+n for n>=0.
    Oracle: Garvan theta2 doc page; Phase 2 RESEARCH.md Pattern 4.
    """
    R = LaurentSeriesRing(QQ, 'q')
    qvar = R.gen()
    result = R.zero()
    n = 0
    while True:
        exp = n * n + n  # = (n+1/2)^2 - 1/4
        if exp >= T:
            break
        coeff = 2 if n >= 0 else 0  # n and -(n+1) both give same exp; coefficient = 2
        result += 2 * qvar**exp
        n += 1
    return QSeries(result.add_bigoh(T), T=T, r=QQ(1, 4))
```

Wait — n=0 gives exp=0, n=1 gives exp=2, n=2 gives exp=6, n=3 gives exp=12, etc.
The pair n=0 (gives exp 0) and n=-1 (gives `(-1)^2+(-1)=0`) both contribute, so coefficient at exp 0 is 2.
The loop above adds 2 for each n>=0, which correctly accounts for both n and -(n+1).

**theta3(q, T):**
Formula: `sum_{n=-inf}^{inf} q^{n^2}`. For n=0 coefficient=1, for n=±k coefficient=2.
Build: add `1` (n=0) plus `2*q^{k^2}` for k=1,2,... while k^2 < T.

```python
def theta3(q, T):
    """Jacobi theta3 = sum_{n=-inf}^{inf} q^{n^2}, truncated to O(q^T).
    
    Coefficient of q^{n^2} is 2 for n>0, 1 for n=0, 0 for non-squares.
    Oracle: Garvan theta3 doc page: theta3(q,50) = 2q^64+...+2q+1.
    """
    R = LaurentSeriesRing(QQ, 'q')
    qvar = R.gen()
    result = R.one()  # n=0 term
    k = 1
    while k * k < T:
        result += 2 * qvar**(k * k)
        k += 1
    return QSeries(result.add_bigoh(T), T=T)
```

**theta4(q, T):**
Formula: `sum_{n=-inf}^{inf} (-1)^n q^{n^2}`. n=0 coefficient=1. For k>0: (-1)^k + (-1)^{-k} = 2*(-1)^k.

```python
def theta4(q, T):
    """Jacobi theta4 = sum_{n} (-1)^n q^{n^2}, truncated to O(q^T).
    
    Coefficient of q^{k^2} is 2*(-1)^k for k>0, 1 for k=0.
    Oracle: Garvan theta4 doc page: theta4(q,50) = 2q^64-2q^49+...+2q^4-2q+1.
    """
    R = LaurentSeriesRing(QQ, 'q')
    qvar = R.gen()
    result = R.one()  # n=0 term: (-1)^0 = 1
    k = 1
    while k * k < T:
        coeff = 2 * ((-1) ** k)
        result += coeff * qvar**(k * k)
        k += 1
    return QSeries(result.add_bigoh(T), T=T)
```
